## 第 1 页 · 封面

**GeneAI 2.0**  
DNA 转录翻译与突变分析平台

- 课程：软件工程 / 生物信息学课程项目
- 技术栈：React 19 + FastAPI + Biopython + SQLite
- 一句话：把中心法则做成可逐步播放、可验证的交互演示

讲稿：  
“我们的项目不是又一个 DNA 序列查看器，而是把 DNA→RNA→蛋白质这条中心法则，以及突变带来的后果，做成可以一步步播放、每一步都能回溯到算法结果的演示平台。”

---

## 第 2 页 · 问题与定位

**要解决的问题**

- 课本里的转录、翻译、移码、无义突变是静态图，学生很难把“碱基变化”与“蛋白质变化”对应起来。
- 很多在线工具直接给出临床结论，容易让学生误以为“一个突变 = 一定致病”。

**我们的定位**

- 面向初高中生物知识背景的**教学演示**与**序列分析**工具。
- 只做序列层面的计算与可视化，不做 AI 问答、不做临床诊断。
- 数据来源、坐标规则、算法限制全部写在页面上。

讲稿：  
“我们刻意没有做 AI 聊天，也没有做疾病风险预测。我们只回答三个问题：这段序列是什么、它会翻译成什么、如果改一个碱基会发生什么。”

## 第 3 页 · 技术架构

```
React SPA（Vite / TanStack Router / Query）
        │ REST /api
FastAPI（10 组路由）
        │
Biopython 算法层（转录 / 翻译 / ORF / 比对 / 限制酶）
SQLite（analysis_records / comparisons / meta）
外部：NCBI ClinVar E-utilities（缓存 + 限流）
```

- 前端只负责“展示 + 播放”，所有生物学结果来自后端。
- 动画帧与 API 返回一一对应，不做随机定时器。

讲稿：  
“动画不是装饰。播放器每一步读取的都是后端返回的 RNA 碱基、密码子或氨基酸，所以暂停在任意一步，画面和算法结果都是一致的。”

## 第 5 页 · 中心法则动画

**教学示例**：`ATGGAACCTTGGTAA` → `AUGGAACCUUGGUAA` → `MEPW*`

- SVG 双螺旋：两条链、碱基对、5′/3′、当前碱基高亮。
- RNA 聚合酶沿模板链 3′→5′ 移动，RNA 按 5′→3′ 生成。
- 核糖体读取密码子，tRNA 带来氨基酸，多肽链逐步增长。
- 控制：开始/暂停/继续/上一步/下一步/重播/0.5–2× 速度。
- 移动端固定控制条，滚动时也能操作。

讲稿：  
“演示时我会先放完一次，再暂停在某个密码子，指出当前 tRNA 的反密码子，然后点下一步，让氨基酸进入多肽链。每一步都可以对回右边的密码子表。”

## 第 6 页 · 核心算法与验证

| 样本 | DNA                | 蛋白    | 说明                  |
| ---- | ------------------ | ------- | --------------------- |
| A    | `ATGGAACCTTGGTAA`  | `MEPW*` | 正常                  |
| B    | `ATGTAACCTTGGTAA`  | `M*`    | 第 2 位密码子提前终止 |
| C    | `ATGAGAACCTTGGTAA` | `MRTLV` | 第 3 位插入 A，移码   |

- 六阅读框 ORF：A 命中 1 个（1–15，`MEPW`），标记「潜在 ORF」。
- 限制酶：`GAATTC…GGATCC…AAGCTT` → EcoRI 2、BamHI 12、HindIII 19。
- GC 滑窗：A 的 5/5 窗口 → 40/40/40。

讲稿：  
“这些数字不是截图里写死的，是现场调用 API 得到的；pytest 里也把同样的样本写成了断言。”

## 第 7 页 · 突变模拟

- 替换 / 插入 / 缺失，位置统一 1-based。
- 同一套算法给出：同义、错义、无义、移码、整码插入/缺失、提前终止、蛋白长度变化。
- 页面同时展示 DNA 差异、RNA 对比、蛋白逐位对比和分析报告。
- 明确免责声明：序列层面预测，不等于疾病结论。

**演示操作**：点「无义突变」预设 → 应用 → 观察蛋白 `MEPW* → MEP*` 与提前终止标记。

---

## 第 8 页 · DNA 序列地图

- 同一坐标轴上分层展示：正/反向 ORF、起始/终止、GC 曲线、限制酶、motif、突变。
- 缩放、平移、框选、上一段/下一段；ORF 与突变可点击查看详情。
- 反向链坐标统一换算为正链；图例与坐标规则固定在页面上。

讲稿：  
“这是把前面所有分析结果放在同一条坐标轴上。学生可以看到一个 ORF 与 GC 曲线、酶切位点的位置关系，而不是在几张表之间来回对照。”

---

## 第 9 页 · ClinVar 证据链

- 数据来自 NCBI ClinVar 官方 E-utilities，不抓取、不伪造。
- 展示基因、变异标识、GRCh38 位置、转录本、临床意义、审查状态、表型、原始链接、查询时间。
- VUS 显示为「意义未明（VUS）」，不会标成致病。
- 缓存 10 分钟 + 频率限制；超时/限流/无结果都有明确提示。

讲稿：  
“这一页我们只做‘证据搬运’，不做二次判读。页面上明确写着：数据库注释不等于诊断结论。”

---

## 第 10 页 · 数据与报告

- SQLite 三张表：`analysis_records`、`comparisons`、`meta`。
- 历史记录支持搜索、本地日期筛选、分页、详情、删除确认、刷新。
- PDF：A4、中文字体、指标、碱基表、饼图、四条链、页脚。
- CSV：UTF-8 BOM，字段完整，可直接进 Excel/pandas。

讲稿：  
“报告不是前端拼字符串，而是后端根据数据库记录重新生成的；PDF 和 CSV 都走同一份记录。”

## 第 12 页 · 演示流程与展望

**5 分钟演示路线**

1. 总览 → 打开演示数据。
2. 转录翻译 → 选示例 B，播放/暂停/下一步。
3. 突变模拟 → 无义预设 → 看蛋白对比。
4. 序列地图 → 缩放 → 点 ORF。
5. 变异数据库 → BRCA1 → 打开详情。
6. 历史 → 导出 PDF/CSV。

**下一步**

- ORF 独立分析页与更多起始密码子。
- 地图多突变叠加、酶切详情。
- 更多物种/转录本参考序列与离线缓存。

讲稿：  
“以上功能均已在本地跑通；没有实现的会明确标注为规划，而不是在演示里伪装成已完成。”
