# GeneAI 2.0 全站 UI 精修与整合报告

> 阶段：GeneAI 2.0 第六阶段（提示词 7）
> 范围：全部 10 个页面 × 桌面 / 平板 / 手机三档
> 日期：2026-11-06

## 1. 目标与方法

本阶段不新增业务模块，集中解决：

- 视觉不统一：标题层级、卡片、按钮、表单、空/错/载入状态。
- 重点页面表现：转录翻译、突变对照、ClinVar 证据、DNA 地图。
- 响应式：1440 / 834 / 390 三档无横向溢出。
- 交互与数据：按钮可用、表单校验、真实 API、无控制台错误。

方法：使用 Playwright 对 10 个页面在三档视口逐页截图，收集 `console.error`、`pageerror`、HTTP ≥ 500 响应和 `scrollWidth`，再对重点页面执行操作（转录播放、突变预设、ClinVar 查询、地图缩放）。

## 2. 全站统一项

| 项目 | 处理 |

## 4. 重点页面

### 转录与翻译

- 双螺旋、转录、翻译按「输入 → 转录 → 翻译 → 结论」纵向排列，动画是主视觉。
- 播放器在桌面右栏 sticky，滚动时始终可见；移动端固定底栏，包含步数、进度、上一步/播放/下一步/重播/速度。
- 转录碱基行自动滚动并居中当前碱基；`Toaster` 移动端底部偏移 96px，避免遮挡控制条。
- 所有碱基、密码子、氨基酸来自 `/api/transcribe`、`/api/translate`，动画不自行编造。

### 基因突变模拟

- 左侧「原始序列 + 突变操作」，右侧「结果 + DNA 差异 + 转录对比 + 蛋白对比 + 报告」。
- DNA 差异原始链红色、突变链绿色；蛋白差异灰（不变）/琥珀（替换）/绿（新增）/红（缺失）/深红（终止）。
- 移动端提交后自动滚动到结果，避免用户长距离寻找。

### 变异数据库

- 查询卡、免责横幅、结果卡片、详情弹窗形成固定层级。
- 临床意义颜色：致病红、可能致病橙、VUS 琥珀、可能良性 / 良性绿；审查状态中文化。
- 显式显示来源、查询时间、缺失字段、原始链接；纯 DNA 查询给出「无法可靠匹配」的明确解释。

### DNA 序列地图

- 独立轨道：刻度、正/负链 ORF、GC 曲线、限制酶、motif、突变，避免挤在一条线上。
- ORF 起止点绿/红圆点；点击 ORF 或突变打开详情；滚轮缩放、拖动平移、Shift 框选。
- 说明卡移到页面底部全宽四栏，桌面左右栏高度基本一致；移动端地图横向滚动并给出提示。

## 8. 已知问题

1. ECharts 与主包体积较大（echart 575 kB、chunk 475 kB），未做进一步拆包。
2. 转录/翻译页在移动端较长，控制条会覆盖视口底部内容，需要留出 `pb-28` 滚动空间。
3. 地图在手机上需要横向滑动，未实现双指缩放。
4. ClinVar 依赖外网与 NCBI 限流；缓存为进程内 10 分钟。
5. 开发态 TanStack Router 浮钮会出现在截图右下角，生产构建不存在。
6. 分析页在未产生结果时右栏仍有留白，这是空状态而非布局错误。
