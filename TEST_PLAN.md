# GeneAI 测试计划（初稿）

| 项目     | 内容                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 文档状态 | 初稿（阶段 1），随实现更新                                              |
| 测试对象 | 前端 React 应用 + FastAPI 后端 + SQLite                                 |
| 测试环境 | Windows 11 / Node 26.5 / Python 3.12+（或 3.14，见风险）/ 本地 Chromium |
| 执行方式 | 手工 + 自动化（pytest / Vitest / Playwright）                           |

---

## 1. 测试目标与范围

### 1.1 目标

1. 验证 DNA 计算**正确**（与 Biopython / 手算对照），而不是仅"能跑"。
2. 验证前后端契约一致（字段、错误码、口径）。
3. 验证主要按钮都有真实行为，没有"点了没反应"。
4. 验证数据持久化与删除、PDF 导出可用。
5. 验证视觉在 1440 / 1024 / 390 三档宽度可用。

### 1.2 范围内

- 序列输入、FASTA 解析、规范化与校验
- 碱基统计、GC/AT、互补、反向互补、RNA 转录
- 全局比对、差异识别、统计口径
- 滑动窗口 GC
- 历史记录 CRUD、搜索、筛选、分页
- 统计接口与 Dashboard
- PDF 生成
- 主题切换与响应式布局

### 1.3 范围外

- 用户注册登录、权限（本项目不做认证）
- 真实基因数据库/NCBI 比对
- 疾病风险解读
- 高并发与生产部署（仅做基础性能检查）
- 浏览器兼容性（只保证 Chromium 系 + 现代 Edge/Chrome）

## 2. 测试层级

| 层级     | 工具                                   | 范围                                   | 运行命令                      |
| -------- | -------------------------------------- | -------------------------------------- | ----------------------------- |
| 后端单元 | pytest                                 | 序列规范化、统计、比对、滑窗、PDF 生成 | `cd server && pytest -q`      |
| 后端接口 | pytest + httpx TestClient              | 13 个端点、错误码、分页、持久化        | `pytest -q tests/test_api.py` |

| 前端组件 | Vitest + Testing Library（浏览器模式） | 表单校验、结果卡、差异表               | `pnpm test`                   |
| 端到端   | Playwright                             | 六页面主流程                           | `pnpm exec playwright test`   |

## 3. 测试数据

固定、可手算、覆盖边界：

| 编号 | 序列                         | 用途        | 期望                                                    |
| ---- | ---------------------------- | ----------- | ------------------------------------------------------- |
| T1   | `ATGC`                       | 最小常规    | len=4，GC=50%，互补 `TACG`，反向互补 `CGTA`，RNA `AUGC` |
| T2   | `AAAA`                       | GC=0 边界   | GC=0，AT=100                                            |
| T3   | `GCGC`                       | GC=100 边界 | GC=100，AT=0                                            |
| T4   | `NNNN`                       | 无有效碱基  | GC=0（不除零），AT=0，N=4                               |
| T5   | `ATGC\nNNNN\n`               | 空白/换行   | 规范化后 len=8                                          |
| T6   | `>seq1 test\nATGCATGC\n`     | FASTA       | 去头与换行，len=8，name 可用 `seq1`                     |
| T7   | `ATGCU`                      | RNA 误输入  | 400 `INVALID_SEQUENCE`，提示 U                          |
| T8   | `ATGX`                       | 非法字符    | 400，指出第 4 位 X                                      |
| T9   | 100,001 bp                   | 超长        | 413 `SEQUENCE_TOO_LONG`                                 |
| T10  | `ATGCGTACGT` vs `ATGCGTTCGT` | 单替换      | substitution=1，identity=90                             |
| T11  | `ATGCGT` vs `ATGCGTTT`       | 尾部插入    | insertion=1（2 个碱基，按事件计 1）                     |
| T12  | `ATGCGTTT` vs `ATGCGT`       | 尾部缺失    | deletion=1                                              |
| T13  | `AAAA` vs `TTTT`             | 全替换      | identity=0，substitution=4                              |
| T14  | `ACGT` vs ``                 | 空序列      | 400                                                     |

> 与 Biopython 对照：`Bio.Seq` 计算互补、`Bio.pairwise2`/`PairwiseAligner` 计算得分，测试中直接调用库函数生成期望值，避免手写期望出错。

## 6. 端到端用例（Playwright）

| ID   | 流程       | 步骤                                  | 期望                                          |

## 10. 缺陷分级与处理

| 级别 | 定义                             | 处理                                |
| ---- | -------------------------------- | ----------------------------------- |
| P0   | 主流程不可用、数据错误、计算错误 | 立即修，阻塞阶段验收                |
| P1   | 次要功能不可用、明显视觉缺陷     | 当前阶段内修                        |
| P2   | 体验问题、文案、边缘情况         | 记录，阶段 8 统一处理               |
| P3   | 建议/优化                        | 写入 `DEVELOPMENT_PLAN.md` 后续增强 |

已知问题必须记录在阶段汇报"当前问题"中，不允许静默跳过。
